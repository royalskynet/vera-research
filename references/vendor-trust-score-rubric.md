# 第三方廠商信任分數評分細則

適用對象：鏈上分析／KYT 供應商、代收付通道、法遵服務商、資料商、其他外包／合作服務商的背景調查評分。

**固定使用**：`vendor-dd` 完整版第八章（報告最後一個正文章）一律依本檔打分，不需使用者另外要求；重點版（`report-format-vendor-dd-brief.md`）的子項權重、評分區間與分級同樣以本檔為準。

權重依據：背景調研要回答的核心是「這家實體強不強、穩不穩」，其次才是合規與能力。跨國合規本就不易，業界頭部同樣有罰款與訴訟，負面事實按嚴重度計分，不因存在就判死。改寫自先前使用的廠商信任評分細則（原權重 20/15/20/20/15/10、三桶 35/30/35）。

## 一、六個子維度定義與權重

| 子維度 | 權重 | 歸屬桶 | 核心問題 | 對應題庫 |
|--------|------|--------|----------|----------|
| 監管認可與處分記錄 | 20% | 合規 | 牌照是否在官方名冊可查、覆蓋轄區多寡、處分的嚴重度與處理狀態 | D2、D6 |
| 合規計劃與數據安全 | 15% | 合規 | AML／制裁篩查／個資合規計劃、第三方安全認證、數據駐留與跨境傳輸 | D3、D4（資安） |
| 產品能力與能力邊界 | 15% | 能力 | 核心能力實際做到什麼、官方明示不支援什麼、量化指標是自報還是有獨立測評 | D7 |
| 客戶互證與生態背書 | 10% | 能力 | 宣稱客戶能否由客戶方公告互證、同業採用度 | D7、D9 |
| 運營可靠性與事故記錄 | 20% | 實體與可靠性 | SLA 與實際可用率、停服／錯誤輸出事件與通報方式、依賴集中度 | D4（可靠性）、D9 |
| 主體實力與穩定 | 20% | 實體與可靠性 | 規模、資本背景、持牌轄區數、營運年限、存續紀錄；簽約與持牌主體是否一致 | D1、D5、D8 |

三桶加總即三維度分數：
- 合規（Compliance）= 監管認可與處分記錄 + 合規計劃與數據安全（滿分 35）
- 能力（Capability）= 產品能力與能力邊界 + 客戶互證與生態背書（滿分 25）
- 實體與可靠性（Strength & Reliability）= 運營可靠性與事故記錄 + 主體實力與穩定（滿分 40）

## 二、信任分數級別與傾向

| 分數區間 | 級別 | 含義 | 傾向 |
|----------|------|------|------|
| 90-100 | A+（卓越） | 實體強大穩定，各維度無重大缺陷 | 較為建議 |
| 75-89 | A（優秀） | 實體強，負面事實屬行業常見程度 | 較為建議 |
| 60-74 | B（良好） | 實體穩定，局部短板 | 較為建議 |
| 45-59 | C（一般） | 實體規模或穩定性不足，或有較重負面事實 | 較不建議 |
| <45 | D（風險） | 主體存疑或重大合規／內控缺陷 | 較不建議 |

傾向只有兩檔，對應 vendor-dd 第七章「结论倾向」，由總分決定。報告是背景調研，不寫採購動作或附加控制措施。

**唯一一票否決**：D6 命中制裁名單直接評 D。其餘負面事實一律在子項內按嚴重度扣分，不另設降級。

## 三、各子維度評分細則

### 3.1 監管認可與處分記錄（20 分）

| 評分 | 標準 |
|------|------|
| 18-20 | 多個主要轄區名冊可查且範圍覆蓋所提供服務；處分屬行業常見程度且已處理或未影響牌照 |
| 14-17 | 主要轄區牌照可查；有罰款、上訴中處分或已整改的無牌事項，牌照未受限制 |
| 10-13 | 牌照僅覆蓋少數轄區或部分服務；或處分涉及核心業務且整改未公開 |
| 6-9 | 牌照範圍與實際業務明顯不符，或牌照受限制、被附加條件 |
| 0-5 | 無牌照可查、牌照被吊銷或暫停，或命中制裁名單 |

### 3.2 合規計劃與數據安全（15 分）

| 評分 | 標準 |
|------|------|
| 14-15 | AML／制裁篩查計劃公開且有獨立審計；個資合規；SOC 2 Type II／ISO 27001 範圍覆蓋所採購服務 |
| 11-13 | 合規計劃公開；認證有但範圍或日期有限，或僅自述；監管指出的缺陷屬局部 |
| 8-10 | 合規計劃僅見自述，或監管認定計劃不合規但未影響牌照 |
| 4-7 | 合規缺口明顯且多次被指出；數據跨境存在風險 |
| 0-3 | 無合規承諾，或有資料外洩／資安事故記錄未整改 |

### 3.3 產品能力與能力邊界（15 分）

通用標準；具體指標依行業替換（見第五節）。

| 評分 | 標準 |
|------|------|
| 14-15 | 核心指標接近業界最高水準且有獨立測評或客戶公開數據支撐；官方明示能力邊界 |
| 11-13 | 核心指標良好；邊界大致可查；量化指標以自報為主但與客戶回饋一致 |
| 8-10 | 指標一般或覆蓋範圍有限，有已知盲區；邊界需從條款或文件反推 |
| 4-7 | 指標明顯落後，或宣稱與實際能力有落差被公開指出 |
| 0-3 | 能力不足以支撐需求，或宣稱的關鍵能力查無實據 |

### 3.4 客戶互證與生態背書（10 分）

| 評分 | 標準 |
|------|------|
| 9-10 | 多家頭部同業客戶可由客戶方公告互證；知名機構深度合作 |
| 7-8 | 部分頭部客戶或知名機構可互證 |
| 5-6 | 客戶名單僅見自述，或互證僅限中小客戶與合作方 |
| 3-4 | 缺乏背書；互證結果與宣稱不符 |
| 0-2 | 宣稱客戶被客戶方否認 |

### 3.5 運營可靠性與事故記錄（20 分）

| 評分 | 標準 |
|------|------|
| 18-20 | SLA 公開且有狀態頁歷史或第三方監測佐證；近三年無重大停服；關鍵依賴有備援 |
| 14-17 | 狀態頁公開；有停服事件但通報及時、修復迅速 |
| 10-13 | SLA 僅見合約或自述；事故通報不完整；存在單一依賴 |
| 6-9 | 有重大停服或錯誤輸出事件且通報遲緩；同業有公開終止合作案例 |
| 0-5 | 頻繁事故、無通報機制，或有資金被盜／客戶資產損失未賠付 |

### 3.6 主體實力與穩定（20 分）

| 評分 | 標準 |
|------|------|
| 18-20 | 賽道頭部規模；營運多年；上市、頂級機構投資或大集團控股；多轄區持牌；簽約與持牌主體一致 |
| 14-17 | 全球或區域前列；資本背景可驗證（融資、控股方）；營運年限長；個別實體需說明或有一般性裁員 |
| 10-13 | 中型或區域型；營運年限短或財務稀少；被收購後整合狀況未明 |
| 6-9 | 有關閉市場、拖欠款項、高管集體離職等斷供訊號 |
| 0-5 | 主體存疑、有破產／倒閉風險，或觸發 D1 紅旗後股權穿透結果不透明 |

## 四、只就證據打分

- 低檔只給**查到的重大負面事實**（無牌、吊銷、制裁命中、資產損失未賠付、主體存疑）。
- 某事項未公開、只有自述 → 落在標準寫「僅見自述／不明」的那一檔，不往負面檔推。
- 每個子項的評分依據寫「查到什麼 [N]」，扣分要指向具體事實；不得以「未能核實」作為扣分理由本身。

## 五、跨行業調整指引

三桶與六子項權重通用於任何第三方廠商。評分時只替換「3.3 產品能力與能力邊界」的衡量指標，其餘五個子項邏輯不變：

| 廠商類型 | 3.3 能力指標範例 | 3.3 能力邊界要查 |
|----------|------------------|------------------|
| 鏈上分析／KYT 供應商 | 鏈上覆蓋數、歸因準確率、誤報率、資料延遲 | 不支援的鏈／資產、歸因標籤來源、隱私幣與跨鏈橋的處理 |
| 代收付／支付通道 | 支援幣種與法幣範圍、到帳時效、失敗率、風控攔截能力 | 不服務的轄區、商戶類別限制（MCC）、單筆／日限額 |
| 法遵顧問／外部法律服務商 | 專業領域覆蓋、過往案件處理經驗、回應時效 | 未執業轄區、不出具意見書的範圍 |
| 資料商／資訊服務商 | 資料覆蓋範圍、更新頻率、準確性可驗證程度 | 資料缺口、授權使用限制 |
| 其他外包服務商 | 依業務性質選 2-3 個可驗證、可量化的核心指標 | 合約排除條款 |

**證據不足**：先照 SKILL.md「證據不足的處置順序」借保留池額度補查、再開深入輪；兩者用盡仍缺，才依第四節落在「僅見自述／不明」那一檔，並寫明已借額度與仍缺什麼。不得省略該子項，也不得用其他子項分數替代。

## 六、多廠商評分

一次評兩家以上時，**每家各出一份獨立評分**，不合併成總表、不寫排名。使用者明說要「比較／對標」才輸出以下總表，欄位順序固定，方便稽核比對：

| 廠商 | 監管處分(20) | 合規安全(15) | 能力邊界(15) | 客戶互證(10) | 運營可靠(20) | 主體實力(20) | 合規桶(35) | 能力桶(25) | 實體與可靠性桶(40) | 總分(100) | 級別 |
|------|------|------|------|------|------|------|------|------|------|------|------|

## 附錄：信任分數計算公式

```
總分 = 監管處分 + 合規安全 + 能力邊界 + 客戶互證 + 運營可靠 + 主體實力（滿分 20+15+15+10+20+20 = 100，已內含權重）

合規桶（35）= 監管處分 + 合規安全
能力桶（25）= 能力邊界 + 客戶互證
實體與可靠性桶（40）= 運營可靠 + 主體實力

總分 ≥ 60 → 較為建議；< 60 → 較不建議
命中制裁名單 → D
```
