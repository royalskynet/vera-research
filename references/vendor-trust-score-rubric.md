# 第三方廠商信任分數評分細則

適用對象：鏈上分析／KYT 供應商、代收付通道、法遵服務商、資料商、其他外包／合作服務商的背景調查評分。

**可選**：只在使用者要評分版時使用；沒要評分就只交 `vendor-dd` 完整版，不主動打分。`vendor-dd` 重點版（`report-format-vendor-dd-brief.md`）的子項權重、評分區間與分級以本檔為準。

權重依據：交易所風控採購服務商，要回答的是「合不合規、能做到哪裡為止、出事時靠不靠得住」，與 `questions-vendor-dd.md`「維度權重」一致。股權穿透與財務只當輔助，併入「主體與財務可持續」。改寫自先前使用的廠商信任評分細則（原權重 20/15/20/20/15/10、三桶 35/30/35）。

## 一、六個子維度定義與權重

| 子維度 | 權重 | 歸屬桶 | 核心問題 | 對應題庫 |
|--------|------|--------|----------|----------|
| 監管認可與處分記錄 | 20% | 合規 | 牌照是否在官方名冊可查、監管具名認可或司法採信、有無制裁／處分／訴訟 | D2、D6 |
| 合規計劃與數據安全 | 20% | 合規 | AML／制裁篩查／個資合規計劃、第三方安全認證、數據駐留與跨境傳輸 | D3、D4（資安） |
| 產品能力與能力邊界 | 20% | 能力 | 核心能力實際做到什麼、官方明示不支援什麼、量化指標是自報還是有獨立測評 | D7 |
| 客戶互證與生態背書 | 10% | 能力 | 宣稱客戶能否由客戶方公告互證、同業採用度 | D7、D9 |
| 運營可靠性與事故記錄 | 20% | 可靠性 | SLA 與實際可用率、停服／錯誤輸出事件與通報方式、依賴集中度 | D4（可靠性）、D9 |
| 主體與財務可持續 | 10% | 可靠性 | 簽約與持牌主體是否一致、有無斷供／倒閉／被收購停產訊號、關鍵人風險 | D1、D5、D8 |

三桶加總即三維度分數：
- 合規（Compliance）= 監管認可與處分記錄 + 合規計劃與數據安全（滿分 40）
- 能力（Capability）= 產品能力與能力邊界 + 客戶互證與生態背書（滿分 30）
- 可靠性（Reliability）= 運營可靠性與事故記錄 + 主體與財務可持續（滿分 30）

## 二、信任分數級別與採購建議

| 分數區間 | 級別 | 含義 | 採購／合作建議 |
|----------|------|------|----------------|
| 90-100 | A+（卓越） | 多維度無顯著風險，監管／司法認可度高 | 優先納入，可作為核心供應商 |
| 75-89 | A（優秀） | 優勢明顯，偶有可緩解風險 | 可納入，建議 POC 驗證 |
| 60-74 | B（良好） | 局部優勢，存在需關注的風險點 | 僅限特定場景使用，需附加控制措施 |
| 45-59 | C（一般） | 明顯短板，風險需高強度緩解 | 謹慎使用，建議作為輔助工具，不作單一依賴 |
| <45 | D（風險） | 重大合規／內控缺陷 | 不建議採購，除非有戰略必要性並附完整緩解方案 |

**一票降級**：合規桶 <20（半數）時，總分再高也最多評 C；D6 命中制裁名單直接評 D。

## 三、各子維度評分細則

### 3.1 監管認可與處分記錄（20 分）

| 評分 | 標準 |
|------|------|
| 18-20 | 持牌主體在官方名冊可查且範圍覆蓋所提供服務；多國監管具名認可或通過權威司法採信檢驗（如 Daubert）；無處分記錄 |
| 14-17 | 牌照可查；有監管合作或法庭質證記錄；僅有輕微且已整改的處分 |
| 10-13 | 牌照僅覆蓋部分服務或部分轄區；無司法採信記錄；無處分 |
| 6-9 | 牌照範圍與實際業務明顯不符，或有未結的監管調查／訴訟 |
| 0-5 | 無牌照可查、有重大處分，或命中制裁名單 |

### 3.2 合規計劃與數據安全（20 分）

| 評分 | 標準 |
|------|------|
| 18-20 | AML／制裁篩查計劃公開且有獨立審計；適用個資法規（如 GDPR／CCPA）合規；數據駐留可選；SOC 2 Type II／ISO 27001 範圍覆蓋所採購服務 |
| 14-17 | 合規計劃公開；認證有但範圍或日期有限；數據本地化可談 |
| 10-13 | 合規計劃僅見自述；認證辦理中；數據跨境安排不明 |
| 6-9 | 合規缺口明顯；無第三方認證；數據跨境存在風險 |
| 0-5 | 無合規承諾，或有資料外洩／資安事故記錄未整改 |

### 3.3 產品能力與能力邊界（20 分）

通用標準；具體指標依行業替換（見第五節）。

| 評分 | 標準 |
|------|------|
| 18-20 | 核心指標行業前列且有獨立測評或客戶公開數據支撐；官方明示能力邊界（不支援清單、限制條款），邊界與宣稱一致 |
| 14-17 | 核心指標良好；邊界大致可查；量化指標以自報為主但與客戶回饋一致 |
| 10-13 | 指標一般，有已知盲區；邊界需從條款或文件反推 |
| 6-9 | 指標明顯落後，或宣稱與實際能力有落差被公開指出 |
| 0-5 | 能力不足以支撐需求，或宣稱的關鍵能力查無實據 |

### 3.4 客戶互證與生態背書（10 分）

| 評分 | 標準 |
|------|------|
| 9-10 | 多家頭部同業客戶可由客戶方公告互證；知名機構深度合作 |
| 7-8 | 部分頭部客戶可互證 |
| 5-6 | 客戶名單僅見自述，或互證僅限中小客戶 |
| 3-4 | 缺乏頭部背書；互證結果與宣稱不符 |
| 0-2 | 客戶知名度低，或宣稱客戶被客戶方否認 |

### 3.5 運營可靠性與事故記錄（20 分）

| 評分 | 標準 |
|------|------|
| 18-20 | SLA 公開且有狀態頁歷史或第三方監測佐證；近三年無重大停服；服務變更提前通知；關鍵依賴（雲、資料源、贊助行）有備援 |
| 14-17 | SLA 公開；有停服事件但通報及時、修復迅速 |
| 10-13 | SLA 僅見合約或自述；事故通報不完整；存在單一依賴 |
| 6-9 | 有重大停服或錯誤輸出事件且通報遲緩；同業有公開終止合作案例 |
| 0-5 | 頻繁事故、無通報機制，或有資金被盜／客戶資產損失事件 |

### 3.6 主體與財務可持續（10 分）

| 評分 | 標準 |
|------|------|
| 9-10 | 簽約與持牌主體一致；營運持續可驗證（財報、融資或登記處申報）；無關鍵人風險 |
| 7-8 | 主體一致；財務僅部分可查；管理層有變動但已穩定 |
| 5-6 | 主體需說明（境外主體與運營實體關聯）；財務資訊稀少 |
| 3-4 | 有裁員、關閉市場、拖欠款項等斷供訊號；高管集體離職 |
| 0-2 | 主體存疑、有破產／倒閉風險，或觸發 D1 紅旗後股權穿透結果不透明 |

## 四、分數區間對應的附加措施建議

- **A+ / A**：可作核心或優先供應商；仍應在合約中明確定價、SLA、數據駐留條款；產品能力主張建議以 POC 盲測覆核，不單憑廠商自述。
- **B**：限定於特定場景使用（如非關鍵路徑、輔助驗證），並附加控制措施：重要案件建議與另一家 A 級以上供應商交叉驗證；合約前索取關鍵證照與認證文件。
- **C**：僅作輔助工具，不單一依賴其結論；採購前需業務單位、風控、法務三方共同確認風險緩解方案；設定使用範圍與監控上限。
- **D**：原則上不建議採購；若因戰略必要性（如區域覆蓋、成本、既有合作歷史）仍需採購，須附完整風險緩解方案並提交更高層級審批。

## 五、跨行業調整指引

三桶與六子項權重通用於任何第三方廠商。評分時只替換「3.3 產品能力與能力邊界」的衡量指標，其餘五個子項邏輯不變：

| 廠商類型 | 3.3 能力指標範例 | 3.3 能力邊界要查 |
|----------|------------------|------------------|
| 鏈上分析／KYT 供應商 | 鏈上覆蓋數、歸因準確率、誤報率、資料延遲 | 不支援的鏈／資產、歸因標籤來源、隱私幣與跨鏈橋的處理 |
| 代收付／支付通道 | 支援幣種與法幣範圍、到帳時效、失敗率、風控攔截能力 | 不服務的轄區、商戶類別限制（MCC）、單筆／日限額 |
| 法遵顧問／外部法律服務商 | 專業領域覆蓋、過往案件處理經驗、回應時效 | 未執業轄區、不出具意見書的範圍 |
| 資料商／資訊服務商 | 資料覆蓋範圍、更新頻率、準確性可驗證程度 | 資料缺口、授權使用限制 |
| 其他外包服務商 | 依業務性質選 2-3 個可驗證、可量化的核心指標 | 合約排除條款 |

**證據不足**：先照 SKILL.md「證據不足的處置順序」借保留池額度補查、再開深入輪；兩者用盡仍缺，才在該子項標「證據不足，暫評區間下限」，並寫明已借額度與仍缺什麼。不得省略該子項，也不得用其他子項分數替代。

## 六、多廠商評分

一次評兩家以上時，**每家各出一份獨立評分**，不合併成總表、不寫排名。使用者明說要「比較／對標」才輸出以下總表，欄位順序固定，方便稽核比對：

| 廠商 | 監管處分(20) | 合規安全(20) | 能力邊界(20) | 客戶互證(10) | 運營可靠(20) | 主體財務(10) | 合規桶(40) | 能力桶(30) | 可靠性桶(30) | 總分(100) | 級別 |
|------|------|------|------|------|------|------|------|------|------|------|------|

## 附錄：信任分數計算公式

```
總分 = 監管處分 + 合規安全 + 能力邊界 + 客戶互證 + 運營可靠 + 主體財務（滿分 20+20+20+10+20+10 = 100，已內含權重）

合規桶（40）= 監管處分 + 合規安全
能力桶（30）= 能力邊界 + 客戶互證
可靠性桶（30）= 運營可靠 + 主體財務

一票降級：合規桶 < 20 → 級別上限 C；命中制裁名單 → D
```

重大採購決策建議由採購、法務、風控三方獨立評定後取各子項平均分，再依上述公式加總，避免單一評分者主觀偏誤。
